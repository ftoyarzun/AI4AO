Method & caveats

  • No retraining, nothing overwritten. Each notebook's own cells were run with Trainer.train and save_checkpoint disabled; checkpoints were only loaded. A checkpoint “loads” if it fits the architecture the notebook builds now — that shows shape compatibility, not that it was trained with the notebook's current settings.
  • Only rollout noise is captured. Each arm is one training run, so gaps of a few nm (Architecture, Activation, Normalization, Pooling) may be training-run variance rather than a property of the design. “Consistent” means the paired Δ exceeds 2.78 standard errors over 5 seeds.
  • The notebook-seed run is a single draw (NumPy is not seeded there), so it can differ from what the notebook originally printed; the duplicated evaluation cell in the Architecture notebook gave 66.4 vs 64.9 nm for the same arm.
  • Evaluated against the current working tree, which has uncommitted edits to AI4AO/LossFunctions.py, MaskGeneration.py and TorchPropagator.py.
  • Not covered: SelfShapingMask, ResidualCNNReconstructor, FrameDenoiser and the other non-comparison notebooks in Tutorials/Advanced.
